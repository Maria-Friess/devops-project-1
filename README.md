# Devops-project-1

pet-проект, который включает создание и доведение до production-подобного состояния небольшого веб-сервис с
полной DevOps-инфраструктурой вокруг него.

- Приложение: Сервис для сохранения статей в личную библиотеку (Frontend, Backend / CRUD API, БД).
- Цель: пройти путь от локального запуска до автоматизированного деплоя в облако с инфраструктурой как кодом, мониторингом, логированием, бэкапами и базовой безопасностью.
- Результат для портфолио: публичный GitHub/GitLab-репозиторий, диаграммы архитектуры, README, CI/CD-пайплайны

## Что на выходе

Пэт-проект по DevOps: веб-сервис с полным циклом доставки — от локального запуска
до автоматизированного деплоя с инфраструктурой как кодом, мониторингом и бэкапами.
