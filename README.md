# Project Root

Краткое описание проекта в одном-двух предложениях.

## Что это

Пэт-проект по DevOps: веб-сервис с полным циклом доставки — от локального запуска
до автоматизированного деплоя с инфраструктурой как кодом, мониторингом и бэкапами.

## Быстрый старт

```bash
# 1. Клонировать репозиторий
git clone <repo-url>
cd project-root

# 2. Локальный запуск
# см. docs/guides/local-setup.md

# 3. Деплой
# см. docs/guides/deployment.md
```

## Структура

| Путь | Назначение |
|------|------------|
| `src/` | Исходный код приложения |
| `docs/architecture/` | Схемы архитектуры, потоки данных, описание сервисов |
| `docs/adr/` | Architecture Decision Records — крупные решения |
| `docs/guides/` | Инструкции: локальный запуск, деплой, разработка |
| `docs/decisions.md` | Журнал решений / индекс ADR |
| `docs/scope-mvp.md` | Границы MVP и требования к продукту |
