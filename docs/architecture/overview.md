## 1. Назначение системы

Что делает сервис и для кого. 2–4 предложения без технических деталей.

## 2. Компоненты

| Компонент | Ответственность | Технология |
|-----------|-----------------|------------|
| app | HTTP API / бизнес-логика | _TBD_ |
| db | Хранение данных | PostgreSQL |
| ingress / proxy | Точка входа, TLS | Nginx / Traefik |
| monitoring | Метрики и алерты | Prometheus + Grafana |
| logging | Централизованные логи | Loki |

## 3. Поток данных

```text
Клиент → Ingress → app → PostgreSQL
                      ↘ /metrics → Prometheus → Grafana → Alertmanager
                      ↘ stdout  → Loki
```

## 4. Окружения

| Окружение | Назначение | Где живёт |
|-----------|------------|-----------|
| local | Разработка | Docker Compose |
| dev | Проверка интеграций | VM / k3s в облаке |
| prod-like | Демо для портфолио | VM / managed K8s |
