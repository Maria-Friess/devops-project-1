# Журнал решений

Единая точка входа в историю значимых решений. Крупные решения оформляются
отдельными ADR в `docs/adr/`, мелкие — записью прямо здесь.

## Формат записи

```text
### YYYY-MM-DD — Краткое название
Контекст → Решение → Последствия
```
